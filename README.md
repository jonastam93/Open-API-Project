# Open-API-Project
Open API project showcasing my favorite cartoons

# Endpoints Used

2D Cartoons
https://api.sampleapis.com/cartoons/cartoons2D

3D Cartoons
https://api.sampleapis.com/cartoons/cartoons3D

# How to Run

1. Download the repository
2. Open the project folder
3. Double click index.html
4. Use the buttons to load cartoon data
